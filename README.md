# zenn-loop-engineering-templates

AIエージェントに目標を渡し、無人で自走させるための**運用ハーネスのひな形**です。
書籍『ループエンジニアリング入門』の付録を、コピペせずに `fork` / `clone` して使える形にしたものです。

書籍: https://zenn.dev/chobitnet/books/loop-engineering-harness

## これは何か

エージェントを毎晩自走させると、**能力ではなく運用で壊れます**。同じ判断を何度もやり直す、
決めたことが記録に残らない、古い記述が残って動作を止める、公開してはいけないものが漏れる。
ここに入っているのは、そういう事故のあとに書かれた文書とスクリプトの骨組みです。

## 使い方

```bash
# 1. このリポジトリを自分のものとして作る(Use this template、または clone)
git clone https://github.com/chobitnet/zenn-loop-engineering-templates.git my-harness
cd my-harness && rm -rf .git && git init

# 2. 置き換えが必要な箇所を洗い出す
grep -rnE '\{\{|__[A-Z_]+__|<[^>]+>' . --exclude-dir=.git
```

プレースホルダは3種類あります。`{{...}}`(文書)、`__PLACEHOLDER__`(スクリプトとループ定義)、
`<...>`(STRATEGY.md)。**中身を読まずに置き換えるだけでは動きません**。
なぜその行があるのかは書籍側に書いてあります。

## 中身

| ファイル | 役割 |
|---|---|
| `CLAUDE.md` | 全エージェント共通の憲法。滅多に変えない |
| `STRATEGY.md` | 採択した戦略と数値マイルストーン。人が承認したものだけ |
| `INTENTS.md` | オーナーが何を望み、AIがどう応えたかのログ。**一次情報の最上位** |
| `loops/` | 1ループ=1ファイル(目的 / 入力 / 手順 / 検証 / 停止条件) |
| `agents/editor.md` | 書き手とは別の文脈で動く「ノーと言える役」 |
| `decisions/` | 人間の判断待ちキュー |
| `memory/` | ループが学んだこと。次回実行時に先に読む |
| `scripts/run_nightly.sh` | 夜間実行のランナー |
| `scripts/harness.nightly.plist` | launchd の定義(macOS) |
| `scripts/check_article.py` | 公開前の秘匿情報チェック。**機械で止める** |
| `scripts/check_style.py` | 文章の癖の検出 |
| `scripts/post_guard.py` | 投稿前のガード(メンション禁止・URL許可リスト・1日上限) |

## プレースホルダは、あなたにしか決められない場所の一覧です

**エージェントに埋めさせないでください。** エージェントが埋めればそれらしい言葉は必ず入りますが、
あなたが線引きを決めていないことに誰も気づかないまま、夜が始まります。

最低限、次の3つは自分の言葉で決めてください。

1. **North Star(数値目標)** — 台帳で測れる形で
2. **対象プロジェクトの表** — 主力でないものを主力と書かない。対象外のものは対象外と書く
3. **人間に聞く項目** — テンプレの列挙を、自分の状況に合わせて具体化する

エージェントに組ませるなら、こう渡してください。

```
このリポジトリのテンプレート一式を元に、ハーネスのリポジトリを作ってください。
- 対象プロジェクトのリポジトリとは別のディレクトリに、gitリポジトリとして作る
- 構成は CLAUDE.md / INTENTS.md / STRATEGY.md / loops / memory /
  decisions{open,resolved} / reports / metrics / assets / scripts
- metrics/ledger.md を最初に作り、空の台帳として初期化する
- CLAUDE.md はテンプレートを配置するだけにして、プレースホルダは埋めないでおく
  (埋めるのは私です)
```

## 前提環境

- **macOS**。定時実行に launchd を使います。他のOSでは cron 等への読み替えが必要です
- **Claude Code**、またはそれに準じる、ファイルの読み書きとコマンド実行ができるコーディングエージェント

## エージェントに任せられない場所が2つあります

ファイルを作る・書く・直すはすべてエージェントに任せられます。それでも人間が自分でやるしかない仕事が
2つ残ります。どちらもダイアログを押す仕事で、どちらも「**信頼してよいか**」を尋ねる問いです。

1. ワークスペースの信頼を尋ねるダイアログ
2. 定時実行から初めて保護領域に触れたときの、OSの許可ダイアログ

無人で走らせた夜に壊れるのは、決まってこの種の場所でした。実例は
`decisions/example-workspace-trust.md` に、起票から解決まで残してあります。

## 注意

`scripts/check_article.py` の検出パターンは**そのままでは役に立ちません**。
あなたの本名・アカウント名・ローカルパス・未公開プロジェクト名に置き換えてください。
このファイルは、実際に情報を漏らした事故のたびに1行ずつ増えたものです。
